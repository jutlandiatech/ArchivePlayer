# ArchivePlayer

An open-source Android app for discovering, streaming and casting the audio and video hosted on the [Internet Archive](https://archive.org).

## Specification

ArchivePlayer is developed specification-first: specs are agreed before tests, and tests are written before implementation.

- [SPECIFICATION.md](SPECIFICATION.md) — requirements, acceptance scenarios, open points and decision log (draft v0.2).
- [UI_SHELL_SPEC.md](UI_SHELL_SPEC.md) — navigation shell, mini-player, theme toggle, flavour differences and element-ID contract.
- [UI_SETUP_SPEC.md](UI_SETUP_SPEC.md) — first-launch setup.
