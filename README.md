Historical version 0.2.0 evidence records 377 tests (173 core, 103 Android UI in `full`, 101 in `foss`) on an API 36 emulator; see [TDD_EVIDENCE.md](TDD_EVIDENCE.md). ## Build

New here? [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md) lists what to install (Android Studio, SDK 37, emulator), how to clone, build both flavours, run the tests, and (optionally) work with an AI coding agent.

Ready-built APKs are in [dist/](dist/).

Open the project in Android Studio, or use the helper from a PowerShell terminal:

```powershell
.\tools\run-gradle.ps1 :core:test
.\tools\run-gradle.ps1 :core:build :app:assembleDebug :app:lintDebug
```

VS Code users can open [ArchivePlayer.code-workspace](ArchivePlayer.code-workspace) and use **Terminal → Run Task**.

## Code map

- `core/src/main/kotlin/com/jutlandiatech/archiveplayer/core` — pure Kotlin/JVM domain logic (no Android dependency): catalog model, query building, format selection, language normalization, filtering, playlist codec, recommendations, settings and download policies.
- `core/src/test/kotlin/...` — specification-linked JUnit tests, named after requirement/acceptance IDs.
- `app/src/main/java/com/jutlandiatech/archiveplayer/ui` — Compose screens, theme and stable element IDs.
- `app/src/main/java/com/jutlandiatech/archiveplayer/playback` — Media3 player, session and (in `full`) Cast integration.
- `app/src/main/java/com/jutlandiatech/archiveplayer/data` — archive.org client, library/settings persistence, downloads.
- `app/src/main/assets` — TextCatalog JSON (English, German, Danish), category map and adult-keyword list (generated by `tools/gen_*.py`).
- `app/src/full` / `app/src/foss` — flavour source sets (Cast only in `full`).
- `app/src/androidTest` — Compose UI tests by element ID, run against a local fixture server (no live archive.org).
- `design` — approved design references and logo masters.
- `site` — GitHub Pages: landing page, share page for playlist links (`site/p/`) and the published category map, deployed by `.github/workflows/pages.yml` (see [docs/APP_LINKS.md](docs/APP_LINKS.md)).
- `docs` — architecture and TDD evidence.
- `tools` — terminal and build helpers.
- `dist` — tested APKs and their SHA-256 checksums.
